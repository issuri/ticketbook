# 🎫 TIMOA
모바일 티켓(캡처 이미지)과 실물 티켓 사진을 모아 **나만의 티켓북**에 붙이고, 관람 기록을 남기는 개인용 앱입니다.
아이폰 우선, 안드로이드·PC에서도 같은 방식으로 사용할 수 있습니다. **비용 0원**, 계정·서버·유료 API 없음.

---

## 1. 어떤 방식으로 만들었나 (기술 선택 이유)

| 선택 | 이유 |
|---|---|
| **PWA(설치형 웹앱)** | 앱스토어 심사·Apple 개발자 계정(연 $99)·Mac/Xcode 없이, 무료 호스팅에 올려 아이폰 홈 화면에 "앱처럼" 설치. 안드로이드도 동일 코드. |
| **순수 HTML/CSS/JS** (빌드 도구 없음) | npm·설치 프로그램 없이 파일 그대로 올리면 끝. 초보자가 따라 하기 쉬움. |
| **IndexedDB** 저장 | 앱을 껐다 켜도 유지. 이미지(Blob)를 큰 용량으로 저장 가능. |
| **Service Worker** | 한 번 열면 이후 비행기 모드에서도 실행. |
| **ZIP 백업** | 티켓 이미지가 원본 그대로 들어간 `.zip` — 파일 앱/PC에서 직접 열어볼 수 있음. |

> 네이티브 앱(Swift, React Native)은 아이폰에 직접 설치하려면 Mac과 Apple 계정이 필요하고, 무료 계정은 7일마다 재설치해야 해서 "0원, 개인용" 조건에 맞지 않아 제외했습니다.

## 3. 폴더 구조

```
ticketbook/
├─ index.html            앱 진입점
├─ manifest.webmanifest  홈 화면 설치 정보
├─ sw.js                 오프라인 캐시 (앱 수정 후 올릴 때 VERSION 숫자 올리기)
├─ css/style.css         디자인
├─ icons/                앱 아이콘
└─ js/
   ├─ app.js             화면·동작 전체
   ├─ db.js              IndexedDB 저장소
   ├─ image.js           이미지 축소(긴 변 2200px, JPEG 90%)·썸네일
   ├─ zip.js             ZIP 만들기/읽기 (외부 라이브러리 없음)
   ├─ backup.js          백업/복원
   └─ ocr.js             (실험) 글자 읽기 — Tesseract.js를 필요할 때만 CDN에서 로드
```

## 4. 내 컴퓨터에서 먼저 실행해 보기 (선택)

1. Python 설치(https://www.python.org/downloads/ , 설치 시 **"Add python.exe to PATH"** 체크)
2. `ticketbook` 폴더 위치에서 터미널(PowerShell)을 열고:
   ```bash
   python -m http.server 5173
   ```
3. 브라우저에서 `http://localhost:5173` 접속. 개발자도구(F12)의 모바일 화면 모드를 켜면 폰 화면으로 볼 수 있어요.

> 이 방식은 컴퓨터에서 확인용입니다. **아이폰에 설치하려면 아래 5번(HTTPS 주소)이 필요**해요.

## 5. 아이폰에 설치하기 (초보자용, 무료, 약 10분)

아이폰에서 오프라인 설치형으로 쓰려면 `https://` 주소가 필요합니다. 무료인 **GitHub Pages**를 사용합니다. (Git 프로그램 설치 불필요, 웹에서 끌어다 놓기만 하면 됩니다.)

### 5-1. GitHub에 올리기
1. https://github.com 에서 무료 가입.
2. 오른쪽 위 **+ → New repository**. 이름을 `ticketbook`으로, **Public** 선택 → **Create repository**.
   - 코드는 공개되지만 **내 티켓 데이터는 올라가지 않습니다**(내 폰 안에만 저장).
3. 새 저장소 화면의 **"uploading an existing file"** 링크 클릭.
4. 컴퓨터의 `ticketbook` **폴더 안의 내용물 전체**(index.html, sw.js, css, js, icons 등)를 끌어다 놓기. (폴더 자체가 아니라 *안의 파일들*)
5. 맨 아래 **Commit changes** 클릭.

### 5-2. 사이트 켜기
1. 저장소의 **Settings → Pages**.
2. **Source**: "Deploy from a branch", **Branch**: `main` / `/ (root)` → **Save**.
3. 1~2분 뒤 같은 화면 위쪽에 `https://내아이디.github.io/ticketbook/` 주소가 나타납니다.

### 5-3. 아이폰에서 설치
1. 아이폰 **Safari**로 위 주소 열기 (⚠️ 크롬 등 다른 앱이 아닌 Safari).
2. 하단 **공유 버튼(□↑)** → **"홈 화면에 추가"** → **추가**.
3. 홈 화면의 **TIMOA** 아이콘으로 실행. 주소창 없는 앱 화면으로 열리면 성공!
4. 처음 한 번은 인터넷이 필요하고, 이후엔 오프라인에서도 실행됩니다.

안드로이드: Chrome에서 같은 주소를 열고 메뉴(⋮) → **"앱 설치"** 또는 **"홈 화면에 추가"**.

> 대안: Netlify(https://app.netlify.com/drop)에 폴더를 끌어다 놓아도 됩니다. 단, 계정 없이 올린 사이트는 잠시 뒤 삭제되므로 가입을 권장합니다.

### 5-4. 앱 업데이트(수정)하기
파일을 고친 뒤 GitHub 저장소에 다시 업로드(같은 이름으로 덮어쓰기)하고 `sw.js`의 `VERSION = 'v1'`을 `'v2'`로 올리세요. 앱을 두 번 열면 새 버전이 적용됩니다. **데이터는 그대로 유지**됩니다.

## 6. 사용법

- **티켓 붙이기**: 하단 가운데 **＋** → ① 이미지 선택(갤러리/촬영) → ② 종류·제목·날짜·장소 → ③ 후기 → **저장**. 이미지나 제목 중 하나만 있어도 저장돼요. 날짜는 오늘로 자동 입력됩니다.
  - **더 기록하기**: 출연자/팀, 좌석, 함께한 사람, 함께 찍은 사진, 티켓북 선택, 카드 색.
  - **✨ 글자 읽기(실험)**: 이미지의 날짜를 자동 입력하고, 읽어낸 글자 조각을 입력칸에 눌러 넣을 수 있어요.
- **둘러보기**: 메인에서 표지를 누르면 티켓북 전환·새로 만들기·꾸미기. 칩으로 유형/연도 필터, 우측 버튼으로 정렬(최신↔오래된)과 보기(모아보기↔연도별).
- **상세**: 카드를 누르면 한 장의 페이지로 열려요. **좌우로 쓸어 넘기면** 이전/다음 티켓. 이미지를 누르면 크게 보기. 우측 위 **수정/삭제**.

## 7. 백업과 복원 (꼭 읽어 주세요)

이 앱의 데이터는 **내 기기의 브라우저 저장소**에만 있습니다. 서버가 없어서 아래 상황에서 사라질 수 있어요.

- 홈 화면의 티켓북 앱을 **삭제**
- Safari 설정에서 **"방문 기록 및 웹사이트 데이터 지우기"**
- 휴대폰 분실·초기화·고장
- (홈 화면에 추가하지 않고 Safari 탭으로만 쓸 때) 오래 열지 않아 iOS가 정리

**그래서 백업 파일이 유일한 안전장치입니다.** 티켓을 열심히 모았다면 한 달에 한 번은 백업하세요. (앱이 30일/변경 10건마다 메인 화면에서 알려줍니다.)

### 백업하기
**보관함 → 백업 파일 만들기** → **파일로 저장/공유** → 공유 시트에서 **"파일에 저장"** → **iCloud Drive**(또는 구글 드라이브 등) 선택. 저장 후 파일 앱에서 `timoa-backup-날짜.zip`이 있는지 확인하세요.
(이 zip을 PC에서 열면 `images/` 폴더에 티켓 이미지·사진이 원본 그대로 들어 있습니다.)

### 복원하기
**보관함 → 백업에서 복원** → zip 선택 →
- **합치기**: 지금 데이터는 유지하고 백업 내용을 추가(같은 티켓은 백업 기준으로 덮어씀)
- **모두 바꾸기**: 지금 데이터를 지우고 백업 그대로

### 기기를 바꿀 때
1. 예전 폰: 백업 파일 만들기 → iCloud Drive에 저장
2. 새 폰: 같은 주소를 Safari로 열어 **홈 화면에 추가**
3. 새 폰: 보관함 → 백업에서 복원 → 저장해 둔 zip → **합치기**
4. 티켓이 모두 보이는지 확인한 뒤에 예전 폰의 앱을 삭제하세요.

## 8. 한계와 알아둘 점

- **기기 간 자동 동기화 없음**: 무료 서버를 쓰지 않는 대신 백업 파일로 옮깁니다. (자동 동기화는 클라우드 계정/서버가 필요해 비용·보안 부담이 생기므로 제외. 대안: 정기 백업을 iCloud Drive에 저장.)
- **이미지 저장 방식**: 긴 변 2200px, JPEG 90%로 다시 저장합니다(스크린샷 글씨는 충분히 선명). 원본 파일 그대로 보관은 아니에요. 원본이 필요하면 사진 앨범에 따로 남겨 두세요.
- **저장 용량**: 브라우저가 허용하는 한도(보통 기기 여유 공간의 상당 부분) 안에서 쓸 수 있고, 티켓 1장당 대략 0.1~1MB입니다. 보관함에서 사용량을 볼 수 있어요.
- **OCR(글자 읽기)**: 첫 사용 시 인터넷으로 엔진·한국어 데이터(수 MB)를 내려받습니다. 무료 오픈소스(Tesseract.js)지만 티켓 디자인에 따라 정확도가 낮을 수 있습니다.
- **글꼴**: 디자인용 무료 글꼴(Black Han Sans, Gowun Dodum, Gaegu)을 Google Fonts에서 처음 한 번 내려받아 기기에 저장합니다. 처음 실행 때 인터넷이 없으면 기본 글꼴로 보이고, 한 번 받은 뒤에는 오프라인에서도 같은 글꼴로 보입니다.
- **QR/바코드는 이미지로만 보관**합니다. 만료된 QR을 다시 쓸 수는 없어요.
- 홈 화면에 추가한 PWA는 iOS 업데이트·정책에 따라 동작이 달라질 수 있습니다. 그래서 백업을 권장합니다.

## 9. 확장 아이디어 (아직 미구현)

다크 모드 · 앱 잠금(Face ID는 웹앱에서 제한적) · 티켓 직접 꾸미기(스티커) · 연말 결산(올해의 관람 통계) · 자동 백업 알림 강화 · 사진 앨범 형태 콜라주 내보내기.
